# あじわいのオーディション採点サイトを作りたい！
ということで、一人（+google geminiくん）でサイトを1から作るまでの過程を記します。
といっても、これを書いているときはすでにrenderを用いたデプロイまでは終了しているので、これから改善していくべき問題について記すことにします。

## 目的
まず、このサイトはこれから毎年2回ずつ行われるであろうオーディションの採点を簡単に行い、そして簡単に集計できることを目的として作られました。

## 制限
主な機能や制限は、Excelで採点を行っていたときのものを引き継ぎました。
1. 採点の提出は一人一回ずつのみ行うことができる。
2. 自分が出演している動画は採点することができない。
3. 採点担当は動画と出演しているメンバーの追加を行える。また、集計結果を閲覧することができる。
4. 採点している途中で画面を閉じても、再度ログインしたときに前回の終了画面を保持する。
5. イベントが終了した際に、次の採点担当に管理権限を委譲することができる。
6. その際、前の管理者は管理者ページにログインできなくなる。
